Pi 上机操作手册
================

本系统的行为特点（队列主导、延迟原因、故障判断）请先阅读：

    docs/系统行为说明.txt


1. 环境准备
--------------
cd ~/edge-visionQA

# 系统依赖
sudo apt install portaudio19-dev alsa-utils libsdl2-mixer-2.0-0

# Python 依赖
pip install -r requirements.txt

# 模型文件
下载 yolov8n.pt 模型文件，放到项目根目录。
确认 models/piper/zh_CN-huayan-medium.onnx 存在（Piper 离线 TTS）。
确认 models/vosk/vosk-model-small-cn-0.22/ 存在（Vosk 离线 ASR）。

# 设置 API 密钥（可选，无密钥仍可离线运行）
export DASHSCOPE_API_KEY="你的阿里云API密钥"
  ⚠️ 每次新开终端都需要重新设置该环境变量
  ⚠️ 未设置密钥时系统自动进入离线模式（本地 TTS + 本地 ASR + 本地 QA）


2. 选择 Pi 配置
-------------
系统在 Linux 上会自动检测并使用 Pi profile（config_pi.yaml）。
config/config.yaml 中的 profile 项作为后备，通常无需手动修改。

如需强制指定 profile：
  export EDGE_VISION_PROFILE=pi


3. 启动系统
--------------
cd ~/edge-visionQA

# USB 摄像头（默认）
python main.py

# CSI 摄像头（树莓派专用）
CAMERA_SRC=csi python main.py

# 指定 USB 摄像头编号
CAMERA_SRC=1 python main.py


4. 正常运行表现
--------------
启动后终端会显示：
  config loaded (compat mode)
  [WARN] DASHSCOPE_API_KEY not set, running in offline mode    （如果未设密钥）
  [WARN] YOLO model load failed: ...                           （如果模型缺失，不崩溃）
  [WARN] TTS model load failed: ...                            （如果模型缺失，不崩溃）
  [MODE] Headless (Pi / no display)
  系统已启动。按 'a' 开始语音输入，按 'q' 退出。

之后终端持续滚动 trace 日志，例如：
  [TRACE][SUBMIT] id=xxx source=decision priority=3 ...
  [TRACE][SELECT] id=xxx ...
  [TRACE][SPEAK_START] ...
  [TRACE][SPEAK_END] ...

正常：每秒有 1~5 条输出，无长时间停顿。

⚠️ headless Pi（SSH 连接）不会弹出摄像头窗口，这是正常现象。
   CSI 摄像头首帧偶尔丢帧 → 系统自动跳过（不退出）。


5. 如何操作
--------------

【GUI 模式（有显示屏的 Pi）】
按 'a' 键 → 开始录音，松开后自动识别并回答。
按 'q' 键 → 退出系统。

【Headless 模式（SSH 远程连接，无显示屏）】
在终端中输入命令 + 回车：

  a + Enter → 启动语音识别（云端/本地引擎尝试）
              如引擎均失败 → 输入框出现 → 直接打字提问
  q + Enter → 退出系统

系统会自动播报环境中的物体（行人、车辆等），无需手动触发。


6. 停止方式
--------------
终端输入 q + Enter，或按 Ctrl+C。
⚠️ 退出后确认命令行已返回，再执行日志回收操作。


7. 异常判断（修正版）
--------------
正常现象（不是异常）：
  * 回答延迟 2~12 秒
  * 多个回答连续播放（堆积释放）
  * 系统"看起来慢"，但持续输出
  * 首帧丢帧 → 自动 continue（不退出）
  * [WARN] 模型加载失败 → 不影响系统运行

异常（必须同时满足以下全部条件）：
  * 超过 10 秒无任何终端输出
  * 且摄像头画面停止更新（有显示屏时）
  * 且无语音播放

异常1：[WARN] DASHSCOPE_API_KEY not set → 系统自动进入离线模式，仍可运行，VLM 功能不可用
异常2：超过 10 秒终端无任何输出（且画面停、语音停）→ 可能卡死，按 Ctrl+C 重试
异常3：摄像头无法打开 → 检查摄像头连接，尝试 CAMERA_SRC=csi 或 CAMERA_SRC=1
异常4：语音输入无响应 → 确认麦克风已连接且权限已授权，或使用 stdin 文字输入
异常5：[WARN] keyboard requires elevated permissions → 正常，自动降级为 stdin 输入
