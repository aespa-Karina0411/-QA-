Pi 上机操作手册
================

【系统行为说明】
本系统为"队列主导（queue-dominant）"的调度系统：

* 所有语音输出按顺序排队播放，不存在并发播放
* 系统在高负载下可能出现明显延迟（2~6秒）
* 延迟是"排队等待"，不是卡死
* 系统不会丢失关键信息（WARNING 零丢失）
* 用户提问后，回答可能延迟，但最终一定会播放
* 输出间隔可能较长（最多约 6 秒），这属于正常排队现象


1. 环境准备
--------------
cd ~/edge-visionQA
pip install -r requirements.txt

下载 yolov8n.pt 模型文件，放到项目根目录。

设置 API 密钥（仅首次）：
  export DASHSCOPE_API_KEY="你的阿里云API密钥"
  ⚠️ 每次新开终端都需要重新设置该环境变量


2. 选择 Pi 配置
--------------
打开 config/config.yaml，确认第 3 行是：
  profile: pi

（如果不是 pi，改为 pi）

确认 config/config_pi.yaml 中没有以下内容：
  pi_sim:
    enabled: true
（如果有，删除这两行）


3. 启动系统
--------------
cd ~/edge-visionQA
python main.py


4. 正常运行表现
--------------
启动后终端会显示：
  config loaded (compat mode)
  系统已启动。按 'a' 开始语音输入，按 'q' 退出。
  系统已启动。按 A 开始语音输入，按 Q 退出。（语音播报）

之后终端持续滚动 trace 日志，例如：
  [TRACE][SUBMIT] id=xxx source=decision priority=3 ...
  [TRACE][SELECT] id=xxx ...
  [TRACE][SPEAK_START] ...
  [TRACE][SPEAK_END] ...

正常：每秒有 1~5 条输出，无长时间停顿。
摄像头窗口会弹出，显示实时画面。


5. 如何操作
--------------
按 'a' 键 → 开始录音，松开后自动识别并回答。
按 'q' 键 → 退出系统。
系统会自动播报环境中的物体（行人、车辆等）。


6. 停止方式
--------------
按 'q' 键，或 Ctrl+C。


7. 异常判断（修正版）
--------------
正常现象（不是异常）：
  * 回答延迟 2~6 秒
  * 多个回答连续播放（堆积释放）
  * 系统"看起来慢"，但持续输出

异常（必须同时满足以下全部条件）：
  * 超过 10 秒无任何终端输出
  * 且摄像头画面停止更新
  * 且无语音播放

异常1：报错 "请设置环境变量 DASHSCOPE_API_KEY" → 未设置 API 密钥，参考第 1 步。
异常2：超过 10 秒终端无任何输出（且画面停、语音停）→ 可能卡死，按 Ctrl+C 重试。
异常3：摄像头窗口全黑 → 检查摄像头连接，或调整摄像头 ID（main.py 中 cv2.VideoCapture(0) 改成 1）。
异常4：语音输入无响应 → 确认麦克风已连接且权限已授权。
